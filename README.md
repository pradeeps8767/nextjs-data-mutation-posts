Next.js Data Mutation Posts

A simple post-sharing application built with Next.js that demonstrates data mutation using modern Next.js features.

Users can create posts, upload images, view posts in a feed, and like posts.

🚀 Features
📝 Create new posts
🖼️ Upload images with Cloudinary
📰 Display all posts in a feed
❤️ Like posts
⚡ Data mutations using Next.js Server Actions
⏳ Loading states
❌ Error handling
🎨 Responsive dark-themed UI
🛠️ Technologies Used
Next.js
React
JavaScript
Next.js Server Actions
Cloudinary
CSS
